# RU tarjima sifati — yakun

## Holat
Aniq MT/atama xatolari tozalandi (qo‘lda + shablon).

**Tuzatilganlar (asosiy):**
- «Закон о ДД» → ПДД
- «знаков концессии» → знаков приоритета
- «маршрутизатор/роутер» → стрелка/указатель
- «без колёс», «запирание» (буксировка)
- «обгон, обгон» → обгон, опережение
- avtomagistral chalkashi
- «дополнительная сеть» → секция
- «по ленте» → по полосе
- «обитаемый шлагбаум» → регулируемый шлагбаум
- «не горящими или не горящими»
- 10 ta savol qo‘lda qayta yozildi

**Qolgan:** faqat yengil uslub (native emas), og‘ir pattern **0**.

Keyingi qadam (siz aytgan): **harf chalkashligi** (A/B/V, kirill «А/Б/В»).
